## 0. 一句话

把起笔页从「表单」改成「欢迎页」：水墨背景、一句大标题、一个胶囊输入框，只做一件事——把 brief 变成一篇文章。

---

## 1. 目标与非目标

### 1.1 目标

- 起笔页只有三样东西：水墨背景、标题、胶囊输入框。
- 输入框是唯一焦点与唯一动作：输入 brief → Enter / 发送 → 创建 job → 跳落墨。
- 水墨背景用纯 CSS 叠层实现，不引图片、不引库。
- 跟随宿主明暗主题；暗色下水墨改为「夜墨发光」。
- 保留键盘与无障碍可用性。

### 1.2 非目标

- 不做「空白稿」「从选题开始」入口（迁到落墨页）。
- 不做「最近文章 / 待审 / 已发布」信息。
- 不做模型选择器（当前无此能力，不放假控件）。
- 不改后端 `/blog/start` 协议。
- 不改四 Tab 结构与其他页面。

---

## 2. 关键决策

| # | 决策 | 理由 | 可逆性 |
|---|---|---|---|
| D1 | 起笔页只保留「开始写作」一个主动作 | 欢迎页的核心是单一焦点，动作越少越清晰 | 高 |
| D2 | 空白稿与选题入口迁到落墨页 | 落墨页已有「新建」与「生产/选题」，不重复 | 高 |
| D3 | 去掉底部「最近」信息 | 起笔页不承担导航，文章列表在落墨 | 高 |
| D4 | 水墨背景用 4 层 radial-gradient + 可选噪点 | 无资源依赖、体积小、可主题化 | 高 |
| D5 | 输入框用胶囊 + auto-grow textarea | 单行像 Gemini，多行可写长 brief | 高 |
| D6 | 不显示模型选择器 | 没有对应能力，避免假控件 | 高 |
| D7 | 左侧图标为纯装饰（笔/墨点） | 保持干净；导入留在落墨 | 高 |
| D8 | Enter 发送、Shift+Enter 换行 | 与对话式输入一致 | 高 |

## 3. 视觉规格

### 3.1 构图

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│                  （水墨晕染，极淡，偏中心偏上）              │
│                                                            │
│                    今天写点什么？                            │
│                                                            │
│      ┌──────────────────────────────────────────────┐      │
│      │ ✒  写一句 brief…                          ↵   │      │
│      └──────────────────────────────────────────────┘      │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

- 内容整体垂直居中，略偏上（约 42% 处）。
- 左右留白大，输入框只占视口约 55%–72%。

### 3.2 背景（水墨）

纸底：

- 亮色：`#fbfaf7`（暖白，不是纯白）
- 暗色：`#111214`（墨黑，不是纯黑）

主晕染（四层，错位叠加）：

```css
background:
  radial-gradient(60% 50% at 38% 34%, rgba(38, 52, 74, 0.12), transparent 70%),
  radial-gradient(50% 45% at 62% 58%, rgba(38, 52, 74, 0.09), transparent 72%),
  radial-gradient(70% 60% at 50% 78%, rgba(38, 52, 74, 0.06), transparent 75%),
  radial-gradient(40% 35% at 24% 70%, rgba(90, 70, 50, 0.05), transparent 70%);
```

要点：

- 冷墨为主（蓝黑），少量暖墨（褐）提层次。
- 最深层透明度 ≤ 0.12，避免脏。
- 不要单圆居中，四层位置错开。
- 暗色反向：墨改为浅蓝灰发光 `rgba(150,170,200,0.10)`。

纸纹（可选）：

- SVG `feTurbulence` 转 base64，透明度 0.03–0.05，`mix-blend-mode: multiply`。
- 不做也不影响主要观感。

动效（可选）：

- 20–30s 极慢漂移，位移 ≤ 3%，`prefers-reduced-motion` 下关闭。
- 不做呼吸缩放。

### 3.3 标题

| 属性 | 值 |
|---|---|
| 文案 | 今天写点什么？ |
| 字号 | 44px（窄屏 32px） |
| 字重 | 300 |
| 行高 | 1.2 |
| 字距 | 0.01em |
| 颜色 | 主文字色，不用纯黑 |
| 与输入框间距 | 56px（窄屏 36px） |

### 3.4 输入框

| 属性 | 值 |
|---|---|
| 宽度 | `min(860px, 72vw)`，最小 320px |
| 单行高度 | 64px |
| 多行最大高度 | 160px |
| 圆角 | 32px（始终胶囊） |
| 背景 | 亮 `#fff`，暗 `#1c1d20` |
| 边框 | 1px `rgba(0,0,0,0.06)`，暗色 `rgba(255,255,255,0.08)` |
| 阴影 | `0 8px 30px rgba(0,0,0,0.08), 0 1px 2px rgba(0,0,0,0.04)` |
| 内边距 | 左右 22px，上下 14px |

内部：

- 左：笔/墨点图标，20px，1.5px 线宽，次要色，纯装饰。
- 中：`textarea`，auto-grow，占位「写一句 brief…」，15px。
- 右：圆形发送按钮，36px，主色；输入为空时 40% 透明度且禁用。
- 不显示模型选择器。

状态：

- 聚焦：阴影加深 + 边框 20% 主色，不加粗描边。
- 输入中：发送按钮由灰变亮。
- 提交中：按钮 loading，输入框禁用。

### 3.5 无障碍

- 标题用 `h1`。
- 输入框有 `aria-label`。
- 发送按钮有 `aria-label`。
- 焦点环使用内描边，不依赖颜色单独传达状态。

## 4. 交互

1. 打开 Tab 即聚焦输入框。
2. Enter 提交，Shift+Enter 换行。
3. 提交：`POST /blog/start { brief, mode: "produce" }`。
4. 成功：跳到落墨，显示「正在生成」，轮询到 slug 自动打开。
5. 失败：输入框下方一行错误文字，不弹窗；输入内容保留。
6. 输入为空：发送按钮禁用。
7. 提交中：禁止重复提交。

---

## 5. 迁移

从起笔页移除：

- 「仅新建空白稿」按钮
- 「从选题开始」按钮
- 底部「最近 / 待审 / 已发布」

对应入口保留位置：

- 空白稿：落墨页顶部「新建」。
- 选题：落墨页「生产」面板里的「生成选题」。
- 最近文章：落墨页左栏列表。

不新增接口，`/blog/start` 仅用 `mode: "produce"`。

### 6.2 样式

新增 `client/start.css` 或并入 `styles.css`：

- `.start-canvas` 水墨背景与暗色
- `.start-title`
- `.start-composer` 与内部元素
- 窄屏媒体查询
- `prefers-reduced-motion`

### 6.3 auto-grow

```js
textarea.style.height = 'auto'
textarea.style.height = `${Math.min(textarea.scrollHeight, 160)}px`
```

在 `onChange` 与 `value` 变化时执行。

## 9. 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 多层渐变在低端设备上纹理带 | 低 | 减少层数或降低透明度 |
| 暗色水墨偏灰 | 中 | 暗色用冷色发光，不用黑 |
| auto-grow 抖动 | 低 | 先置 auto 再测高度 |
| 入口迁移后用户找不到空白稿 | 中 | 落墨页「新建」保持显眼 |
| 胶囊输入框在窄屏过窄 | 低 | 最小宽度 320px，低于则 90vw |
